# Flask Blog 🐍

A blog web application built while following [Corey Schafer's Flask tutorial series](https://www.youtube.com/@coreyms).

This project helped me learn the fundamentals of backend web development with Flask, including application structure, database integration, user authentication, and more.

## ✨ Features

- User registration and login
- Password hashing and authentication
- Create, update, and delete blog posts
- User profile management with profile pictures
- Password reset functionality through email
- Database integration using Flask-SQLAlchemy
- Application factory and modular project structure

## 🛠️ Technologies Used

- **Python** — Backend programming
- **Flask** — Web framework
- **Flask-SQLAlchemy** — Database integration
- **SQLite** — Database
- **Flask-Bcrypt** — Password hashing
- **Flask-Login** — User session management
- **Flask-Mail** — Email functionality
- **HTML & CSS** — Frontend

## ⚙️ Setup and Installation

1. Clone the repository:

   ```bash
   git clone <your-repository-url>
   cd <repository-folder>
   ```

2. Create a virtual environment:

   ```bash
   python -m venv venv
   ```

3. Activate the virtual environment.

   **Windows:**
   ```bash
   venv\Scripts\activate
   ```

   ** macOS / Linux:**
   ```bash
   source venv/bin/activate
   ```

4. Install the dependencies:

   ```bash
   pip install -r requirements.txt
   ```

5. Configure the required environment variables, including the Flask secret key and email settings, if needed.

6. Run the application using your project's entry point:

   ```bash
   python run.py
   ```
